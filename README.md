# Sewer Designer (Android)

This branch provides a complete Android app that can model simple sewer pipe hydraulics locally.

How to run
1. git fetch origin
2. git checkout feature/android-local-hydraulics
3. Open the project in Android Studio
4. Let Gradle sync, then run the app on an emulator or device.

What is included
- Local hydraulics engine (Manning & Hazen–Williams)
- Jetpack Compose UI with English/Arabic translations
- Simple editor to add pipes
- Local persistence using Room
- Unit test for hydraulics
